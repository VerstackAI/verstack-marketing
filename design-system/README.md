# Design system

The rules and names for Verstack marketing graphics, in the same shape as the app's design systems in `VerstackAI/verstack-mvp/apps/design-system`.

| File | What |
| --- | --- |
| `RULES.md` | Non-negotiables, things not to use, the review checklist |
| `COMPONENT_INDEX.md` | Canonical names for frames, drawings, app UI, motion and layouts, and the app canonical names for every captured screen and part |
| `DESIGN_SYSTEM.md` | Principles, foundations, drawings, app UI, motion, voice |
| `CHANGELOG.md` | What changed and when |
| `AGENT_CONTEXT.md` | Where things live and how to build them, for coding agents |

The browsable version, with live previews and every asset, is the **Verstack Marketing** design system on claude.ai.
