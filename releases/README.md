# Releases

One folder per product update, named `YYYY-MM-short-name` (for example `2026-11-repeat-repairs`).

Each folder holds:

- `linkedin-1080x1350.png`: the LinkedIn feed image
- `email-1200x630.png`: the email and link-preview image
- `notes.md`: the headline, the status (Live, Rolling out or In pilot), and the dates the email and post went out

The edited HTML for each image stays in `templates/`, named after the release, so its links to the fonts and logos keep working.

Only add a folder once the release copy is approved. This repo is public.
